# Drive Wise Dealer — Frontend UI Revamp

A complete frontend-only redesign of the original car-dealer project.

## Open the website

Open `home.html` directly in a browser, or serve the folder with a local static server.

Recommended with VS Code:
1. Install the **Live Server** extension.
2. Right-click `home.html`.
3. Select **Open with Live Server**.

Alternative with Python:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/home.html`.

## Included frontend features

- Modern responsive home page
- Video hero with fallback image
- Searchable and filterable vehicle inventory
- 24 vehicle listings across 8 brands
- Dynamic vehicle detail pages and image galleries
- Favorite buttons, share UI, and toast feedback
- Login and signup modal UI
- Contact, test-drive, inquiry, and newsletter form UI
- Mobile navigation and mobile filter drawer
- Consistent visual system, spacing, typography, cards, and buttons

## Important

This package intentionally completes the **frontend UI only**. Login, signup, inquiries, newsletter subscriptions, favorites, and payments are demo interactions and still require backend/database integration for production use.
